## 发布顺序建议

1. 视频发到 P01–P03 时先发 01（认知铺垫，最容易被转发）；
2. P09–P11 期间发 02，配合「属性与类型」的搜索长尾；
3. P12–P14 期间发 03、04，这两篇偏实战，适合嵌视频卡片；
4. P15–P16 收官时发 05，把合集与代码仓一起收口。

每篇结尾都留了引导位，发布时把视频卡片与仓库链接补上即可（仓库地址由你自己的托管决定，文章里没有写死 URL）。

- 所有 `pNN_sNN.slint` 引用、视频时间点、代码块均经过逐项比对，代码块逐字来自仓库文件；
- 版本差异（edition 1.20 vs 本机 1.18.1）、wasm / 打包未做本机编译验证等，文中都如实标注，没有把未验证的东西写成「已跑通」。
