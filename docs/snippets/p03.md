# P03 · 讲解摘录

以下片段是课程幻灯片上的教学摘录：命令行、Cargo.toml、宿主语言（Rust / C++ / JS / Python）、跨版本语法对照、伪代码，或必须嵌在父组件里才有意义的局部语法。它们**不是独立可编译的 .slint 文件**，代码片段按原样保留。

> 本集的完整可运行上下文在 [`memory-game/step02-tile/`](../../memory-game/step02-tile/)，其中 `ui/app-window.slint` 与 `src/main.rs` 含这些片段引用的 `MemoryTile`、`TileData`、`MainWindow` 等定义。运行：`cargo run -p step02-tile`
