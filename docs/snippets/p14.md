## P14 06:55 · 动态增减元素

if 移除元素，visible 只隐藏

```slint
HorizontalLayout {
    Rectangle { background: green; }
    if root.show-details : Rectangle {
        background: orange;
    }
    Rectangle { background: blue; }
}
// show-details = false 时，绿蓝平分宽度
```
