## P08 03:03 · := 命名语法

起名后即可点路径访问

```slint
export component MyApp inherits Window {
    hello := MyButton {
        x: 0;
        text: "hello";
    }
    world := MyButton {
        x: hello.x + 50px;   // 用名字引用其他元素
        text: "world";
    }
}
// root / self / parent 是三个保留名
```

- 镜号：第 9 镜 · 视频定位 `P08 03:03`
- 未纳入独立示例的原因：2:14: Unknown element 'MyButton'

## P08 04:46 · export 与 import

默认私有，导出才可见

```slint
// button.slint 里：
export component Button { /* ... */ }

// main.slint 里：
import { Button } from "./button.slint";

export component App inherits Rectangle {
    Button { /* ... */ }
}
```

- 镜号：第 14 镜 · 视频定位 `P08 04:46`
- 未纳入独立示例的原因：5:24: Cannot find requested import "./button.slint" in the include search path

## P08 05:04 · 相对于当前文件

路径相对当前文件，且要带扩展名

```slint
// ui/main.slint
import { Button } from "./button.slint";
// 写成 "button.slint" 会被当成库名，解析失败

export component App inherits Rectangle {
    Button { text: "ok"; }
}
```

## P08 06:03 · 目录，还是项目文件

指向目录是松散引入，指向项目文件可保留库设置

```slint
{
    "edition": "1.20",
    "main": "ui/main.slint",
    "library-paths": {
        "mylibrary": "third_party/mylibrary",
        "otherlibrary": "third_party/otherlib/slint-project.json"
    }
}
```
