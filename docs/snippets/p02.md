## P02 01:36 · 构建依赖要加 --build

```bash

# 构建依赖：只在编译期跑
```

## P02 03:28 · run 是事件循环，不是显示

include_modules! 引入 build.rs 的产物

```rust

    app.run()                       // 关窗才返回
```

## P02 06:45 · feature 只写在命令行

环境变量与 feature 缺一不可

```bash

# 发布：不带 feature，走编译期生成
cargo build --release
```
