## P05 03:07 · for tile[i] in memory_tiles

模型变，界面自动跟着变

```slint
for tile[i] in memory_tiles : MemoryTile {
    x: mod(i, 4) * 74px;
    y: floor(i / 4) * 74px;
    width: 64px;
    height: 64px;
    icon: tile.image;
    open_curtain: tile.image_visible || tile.solved;
    clicked => {
        tile.image_visible = !tile.image_visible;

}
```
