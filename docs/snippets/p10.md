## P10 05:23 · \{表达式} 直接嵌入

\{...} 是字符串插值

```slint
Text {
    text: "Value: \{round(slider.value)}";
}
// 等价于 "Value: " + round(slider.value)
```

## P10 06:08 · 写进 Rust 就失效

格式化交给 Rust，展示交给 Slint

```rust
// 宏里不能写 \{...} 插值
slint::slint! {
    export component App inherits Window {
        in property <string> label;
        Text { text: label; }
    }
}

fn main() {
    let app = App::new();
    app.set_label(format!("Count: {}", 3).into());
}
```
