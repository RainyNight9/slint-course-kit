## P16 02:41 · 共享一份模型

Rc 共享数据，as_weak 断开循环

```rust
let model = std::rc::Rc::new(slint::VecModel::from(tiles));
ui.set_tiles(model.clone().into());

let weak = ui.as_weak();
ui.on_reset(move || {
    let ui = weak.upgrade().unwrap();
    ui.set_tiles(model.clone().into());
});
```
