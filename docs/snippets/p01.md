## P01 05:45 · debug 与 pure

pure 函数可进绑定；debug 是回调里的调试出口

```slint
pure function half(n: float) -> float {
    return n / 2;
}

width: half(root.width);  // 纯函数才能进绑定

clicked => {
    debug("clicked!");   // debug 可在回调里直接用
}
```
