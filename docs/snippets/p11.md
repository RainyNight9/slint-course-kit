## P11 05:07 · 比属性多一档

protected 只对直接子类开放

```slint
export component Base {
    public function hello() { debug("hi"); }
    protected function inner() { debug("in"); }
    private function local() { debug("lo"); }
}

export component Sub inherits Base {
    init => { self.inner(); }   // 直接继承：可以
}
```
