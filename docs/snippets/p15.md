## P15 06:11 · 拖拽里的算术

记基准值 + 位移差 + 夹紧上下限

```slint
touch := TouchArea {
    property <float> pressed-value;
    moved => {
        if (self.enabled && self.pressed) {
            root.value = max(root.minimum, min(root.maximum,
                self.pressed-value + (self.mouse-x - self.pressed-x)
                * (root.maximum - root.minimum) / (root.width - handle.width)));
        }
    }
}
```

## P15 07:00 · 弱引用断开循环

as_weak 进回调，upgrade 再取回来

```rust
let recipe = Recipe::new().unwrap();
let recipe_weak = recipe.as_weak();

recipe.on_button_pressed(move || {
    let recipe = recipe_weak.upgrade().unwrap();
    let mut v = recipe.get_counter();
    v += 1;
    recipe.set_counter(v);
});

recipe.run().unwrap();
```
