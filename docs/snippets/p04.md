## P04 04:50 · 宽度动画滑开

宽度归零 = 幕布拉开

```slint
// 左幕布
Rectangle {
    background: #193076;
    width: open_curtain ? 0px : (parent.width / 2);
    height: parent.height;
    animate width { duration: 250ms; easing: ease-in; }
```
