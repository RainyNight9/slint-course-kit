## P12 05:25 · export global Logic

全局是宿主可见的另一扇门

```slint
export global Logic {
    in-out property <int> the-value;
    pure callback magic-operation(int) -> int;
}

// Rust 侧：
app.global::<Logic>().on_magic_operation(|v| v * 2);
app.global::<Logic>().set_the_value(42);
```

## P12 05:48 · 要在主组件文件里导出

泛型方法拿到单例句柄，套路同组件

```rust

// export global Logic {
//     in-out property <int> the-value;
//     pure callback magic-operation(int) -> int;

    let app = App::new();
    app.global::<Logic>().set_the_value(42);
    app.global::<Logic>().on_magic_operation(|v| v * 2);
```

## P12 06:33 · 使用者看不到全局

组件对外只暴露自己的属性名

